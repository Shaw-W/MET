# 功能与任务配置说明

MET 推荐使用内置的 **「核心日常（推荐）」** 预设一键运行。以下为当前已针对《悠久之树》4.0 界面实机校准的全部任务与可配选项。

---

## 已校准任务一览

| 任务 | 说明 | 可配选项 |
| --- | --- | --- |
| **启动游戏** | PC 端自动拉起 `eternaltree.exe` / ADB 自动启动官服或 B服，自动关闭登录公告、礼包星形弹窗与每日签到弹窗进入主界面（支持从任意子页回主页） | 前置任务：`启动 eternaltree.exe`（自动判断 / 手动路径） |
| **体力补给** | 前置进入「活动 → 福利放送」连续领取每日物资（12点/18点）与在线奖励（`And` 亮金色 + 丝带双重校验，自动右滑领 60 分钟档，不误点已领或物品详情） | `领取每日物资`、`领取在线奖励` |
| **月卡扫荡** | 自动进入主页「月卡 → 特许关卡」一键扫荡全部剩余特许关卡（`0关/0次` 自动跳过），等待动画播完后自动将「奖励总览」截图留档至 `debug/rewards/` | — |
| **行会日常** | 自动从菜单抽屉进入行会执行每日签到与物资捐赠，支持识别剩余捐赠次数与已完成自动跳过 | `行会签到`、`行会捐赠`、`每日捐赠次数上限`（1/2/3 次） |
| **联机自动战斗** | 进入「联机 → 自动战斗」挂机连战，支持从主页/大厅/战斗中任意状态接管；按「战斗结算」上升沿从 0 实时计数并播报关卡名；战斗 HUD 软卡死监控与 PC 自动强杀重启续刷；全员重伤等待队友后再安全撤退（绝不消耗复活道具） | `卡死重启判定时间`（2/3/5 分钟 / 仅统计 / 不看护）、`全员重伤等待队友时间`（默认 10 分钟 / 5 / 15 / 立即 / 不撤退）、`同步战斗设置`（6 项开关 + 2 项自动吃药） |
| **领取奖励** | 收尾统一清红点：一键领邮件、任务（日常含活跃宝箱/主线/成就）、探求者之书 & 器灵讨伐书（先领任务经验再领等级奖励）、探求者手记 | 4 项总开关及各子分类独立开关 |

## 联机自动战斗特别说明

- **绝不花费额外货币**：勾选「同步战斗设置」关闭时完全沿用你游戏内已有配置；遇到「全员重伤」弹窗时强制选中右侧「无力战斗，全员撤退」，绝不触发复活道具消耗。
- **卡死与断网自动兜底**：
  - 正常长战期间左上角倒计时持续变化，不会误判卡死；
  - 若出现无 UI 软卡死、战斗倒计时停滞或无限加载，超过设定时长（默认 5 分钟）自动截屏留档至 `debug/coop_freeze/` 并触发强杀重启续刷；
  - 遇到「网络已断开，即将重新登录」弹窗点确认后若黑屏超时（45 秒），也会自动强杀重启续刷。
