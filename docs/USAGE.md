# MET（Maa Eternal Tree）使用手册与连接配置教程

本指南面向 Windows (`x86_64`) 用户，详细介绍如何下载启动、**配置 PC 桌面端（Win32）与安卓模拟器（ADB）连接**、配置 4.0 任务选项以及排查常见问题。

---

## 1. 下载与解压

1. 前往 [Releases](https://github.com/Shaw-W/MET/releases) 下载最新版本的 `MET-win-x86_64-*.zip`。
2. 将压缩包**完整解压**到一个纯英文/无特殊字符路径（例如 `D:\MET\`），确保目录结构完整：
   ```text
   MET/
   ├── MET.exe                 # 主程序（MXU 前端）
   ├── agent/
   │   └── met-service.exe     # Go 辅助服务（前置启动 / 联机计数 / 卡死重启）
   ├── maafw/                  # MaaFramework 核心运行时与动态库
   ├── interface.json          # PI V2 协议配置
   ├── logo.png
   └── resource/               # 识别模型、Pipeline 与模板素材
   ```
3. **杀毒软件提示**：若 Windows Defender 或第三方安全软件拦截 `MET.exe` 或 `agent/met-service.exe`，请将整个 `MET/` 目录加入白名单后重新解压。
4. 无需安装 Python、Go 或任何额外运行环境；首次双击 `MET.exe` 需初始化 WebView2，约需 3～10 秒。

## 2. 连接配置教程

MET 统一以 **横屏 16:9、短边 720（1280×720）** 作为识别基准。你可以按自己的游玩习惯选择 **PC 桌面端** 或 **安卓模拟器**。

### 方式 A：Win32 PC 桌面端（推荐）

#### 第一步：以管理员身份运行 MET（关键）
《悠久之树》PC 客户端通常以管理员权限运行；若 MET 权限低于游戏，Windows 会拦截鼠标点击与截图。
- **推荐做法**：右键 `MET.exe` → **属性** → **兼容性** → 勾选 **「以管理员身份运行此程序」** → 点击确定，以后直接双击即可。

#### 第二步：检查游戏窗口设置
1. 启动《悠久之树》PC 客户端（窗口类名 `UnityWndClass`，标题 `eternaltree` / `悠久之树`）。
2. 在游戏内设置为 **标准 16:9 窗口模式**（支持 `1280×720`、`1920×1080`、`2560×1440` 等标准 16:9 分辨率，引擎会自动按短边 720 等比缩放）。
3. 挂机期间请**不要最小化游戏窗口**（最小化后 Windows 会暂停渲染画面，导致无法截图；若已最小化，开启前置启动会自动还原）。

#### 第三步：在 MET 中连接 PC 窗口
1. 打开 `MET.exe`，在设备连接栏将控制器类型切换为 **`Win32 桌面端`**。
2. 点击 **刷新 / 扫描窗口**，列表会自动匹配到 `eternaltree`（或 `悠久之树`）。
3. 选中该窗口并点击 **连接**（默认已配置最优组合：`FramePool` 截图 + `Seize` 键鼠，通常无需手动修改）。
4. 连接成功后，上方/预览区应能正常显示游戏画面，即表示配置完成。

#### 第四步：配置自动启动游戏（可选，强烈推荐）
1. 在任务栏顶部或前置任务设置中，开启 **`启动 eternaltree.exe`**。
2. **游戏路径**默认选 **「自动判断」**：会自动读取上次连接记录以及常见 TapTap 安装目录（`C/D/E/F:\TapTap\PC Games\176733\*\eternaltree.exe`）。
3. 若你安装在自定义目录，切换为 **「手动填写」** 并选择你的 `eternaltree.exe` 路径即可。
4. 若游戏已经在运行，前置任务会**秒级检测跳过**，不会重复多开。

> [!TIP]
> **PC 端联机卡死自动重启续刷前提**：请保持 MET 设置中的 **本地 Web 服务** 为开启状态（默认开启，端口 `12701`）。发生断网黑屏或软卡死时，`agent/met-service.exe` 会自动强杀并重启游戏、重连控制器并恢复联机。

### 方式 B：ADB 安卓模拟器

#### 第一步：配置模拟器分辨率与 ADB 调试
1. 推荐使用 **MuMu 模拟器 12**（或其他支持标准 ADB 的安卓模拟器）。
2. **显示设置**：分辨率设为 **`1280×720`（平板/横屏模式）**，DPI 建议 `240`，关闭异形屏/刘海屏。
3. **开启 ADB 调试**：
   - **MuMu 模拟器 12**：右上角菜单 → 设置中心 → 其他 → 开启 **ADB 调试**（默认端口通常为 `16384`，多开顺延 `16416` 等）。
   - **雷电模拟器**：设置 → 其他设置 → 开启 **ADB 调试**（默认端口通常为 `5555`）。

#### 第二步：在 MET 中连接模拟器
1. 启动模拟器，打开 `MET.exe`。
2. 在连接设置中选择控制器 **`ADB 模拟器`**。
3. 选择对应服区资源：
   - **官服**：默认 `resource/base`
   - **B服**：自动叠加 `resource/bilibili`（独立包名 `com.bilibili.yjzs.bili`）
4. 点击 **扫描设备**，选中扫描到的模拟器实例并点击 **连接**。
5. **若扫描不到设备**：
   - 请确认模拟器已完全启动并已开启 ADB 调试；
   - 可在连接设置中手动指定模拟器自带的 `adb.exe` 路径（例如 `MuMuPlayer-12.0\shell\adb.exe`）与连接地址（例如 `127.0.0.1:16384`）。

## 4. 日志、截图留档与常见问题（FAQ）

### 自动留档目录说明
所有运行日志与异常截图均保存在运行目录下的 `debug/` 文件夹：
- `debug/maafw.log`：MaaFramework 底层详细识别与执行日志
- `debug/met_coop_watchdog.log`：Go 服务联机计数、`[Scan]` 软卡死心跳与重启续刷日志
- `debug/coop_freeze/`：联机触发卡死、断网或全员重伤时的 720p 现场截图
- `debug/rewards/`：月卡扫荡结束后的「奖励总览」产物截图
- `debug/on_error/`：Pipeline 节点异常失败时的自动现场截图

### 常见问题
- **Q：双击 `MET.exe` 后窗口没立刻弹出？**
  - A：首次启动会初始化本地 WebView2 缓存，约需数秒；同时可查看右下角系统托盘是否有 MET 图标。
- **Q：Win32 端扫不到窗口，或连接后能截到图但点不动？**
  - A：绝大多数情况是**权限不足**。请右键 `MET.exe` 选择 **「以管理员身份运行」**，并确保游戏未最小化、截图/输入方式为 `FramePool` + `Seize`。
- **Q：识别不到按钮或点击位置偏移？**
  - A：请确认游戏窗口或模拟器为标准 **16:9（推荐 `1280×720` 或 `1920×1080`）**，未开启系统异形缩放或拉伸黑边。
- **Q：如何反馈 Bug？**
  - A：请前往 [GitHub Issues](https://github.com/Shaw-W/MET/issues) 提交反馈，并附上：
    1. 出现问题时的控制器类型（Win32 / ADB）、任务名称与选项；
    2. `debug/maafw.log`、`debug/met_coop_watchdog.log` 及当日日志文件；
    3. `debug/on_error/` 或 `debug/coop_freeze/` 中的对应截图。
