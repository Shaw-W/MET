# MET（Maa Eternal Tree）使用手册

本指南面向 Windows (`x86_64`) 用户，说明如何下载、连接《悠久之树》（ADB 模拟器或 Win32 PC 端）、配置任务以及排查常见问题。

---

## 1. 下载与启动

1. 前往 [Releases](https://github.com/Shaw-W/MET/releases) 下载最新版本的 `MET-win-x86_64-*.zip`。
2. 将压缩包**完整解压**到一个无特殊字符的目录（例如 `D:\MET\`），确保以下文件位于同级目录：
   ```text
   MET/
   ├── MET.exe
   ├── maafw/
   ├── interface.json
   ├── logo.png
   ├── scripts/
   └── resource/
   ```
3. 直接双击运行 `MET.exe`（无需安装 Python 或其他运行库）。首次启动需初始化 WebView2，约需 3～10 秒。

---

## 2. 连接设置

MET 统一使用 **横屏 16:9、短边 720（1280×720）** 作为识别基准。

### 方式 A：ADB 安卓模拟器（推荐）

1. 推荐使用 **MuMu 模拟器 12**（或其他支持 ADB 调试的安卓模拟器）。
2. 在模拟器设置中将显示分辨率设为 **`1280×720`（平板/横屏模式）**，并开启 **ADB 调试**（MuMu 12 默认端口一般为 `16384`）。
3. 在 MXU 界面选择控制器 **`ADB 模拟器`**，点击扫描设备并连接。

### 方式 B：Win32 PC 桌面端

1. 启动《悠久之树》PC 客户端（窗口类名 `UnityWndClass`，标题 `eternaltree` / `悠久之树`）。
2. 建议游戏窗口保持 **16:9 窗口模式**（支持 `1280×720` / `1920×1080` / `2560×1440` 等标准 16:9 分辨率，引擎会自动按短边 720 缩放），避免最小化窗口。
3. 在 MET 界面选择控制器 **`Win32 桌面端`**，点击刷新即可自动匹配窗口；可在前置任务中启用 **`启动 eternaltree.exe`** 自动拉起游戏。
4. **管理员权限提示**：若游戏 PC 端是以管理员权限启动的，请右键 `MET.exe` 选择 **「以管理员身份运行」**，否则 Windows 会拦截截图与输入。

## 4. 常见问题（FAQ）

- **Q：双击 `MET.exe` 后窗口没立刻弹出？**
  - A：首次启动会初始化本地 WebView2 缓存，约需数秒；同时可查看右下角系统托盘是否有 MET 图标。
- **Q：Win32 端扫不到窗口或连接后黑屏/点不动？**
  - A：请确认游戏未最小化，并尝试右键以管理员身份运行 `MET.exe`；或在设置中确认 Win32 截图/输入方式为 `FramePool` + `Seize`。
- **Q：识别不到按钮或点击偏移？**
  - A：请确认模拟器或游戏窗口为标准 **16:9（推荐 1280×720）**，且未开启异形刘海/非标准缩放。
- **Q：如何反馈 Bug？**
  - A：请前往 [GitHub Issues](https://github.com/Shaw-W/MET/issues) 提交反馈，并附上：
    1. 出现问题时的任务名称与选项配置；
    2. 运行目录下 `debug/` 中的 `maafw.log` 与当日日志文件；
    3. 卡住界面的截图（如方便）。
