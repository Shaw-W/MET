# 常见问题与日志反馈（FAQ）

---

## 1. 自动留档与日志目录

所有运行日志、异常现场截图与扫荡产物图均保存在运行目录下的 `debug/` 文件夹：

| 路径 | 内容说明 |
| --- | --- |
| `debug/maafw.log` | MaaFramework 底层详细识别、OCR 与节点执行日志 |
| `debug/met_coop_watchdog.log` | Go 服务联机连战计数、`[Scan]` 软卡死心跳与重启续刷日志 |
| `debug/coop_freeze/` | 联机触发卡死、断网或全员重伤时的 720p 现场截图 |
| `debug/rewards/` | 月卡扫荡结束后的「奖励总览」产物截图 |
| `debug/on_error/` | Pipeline 节点异常失败时的自动现场截图 |

## 2. 常见问题排查

- **Q：双击 `MET.exe` 后窗口没立刻弹出？**
  - A：首次启动需初始化本地 WebView2 缓存，约需 3～10 秒；若仍未显示可检查右下角系统托盘是否有 MET 图标。
- **Q：提示找不到 `agent/met-service.exe` 或杀毒软件报毒？**
  - A：部分安全软件会误报 Go 编译的可执行文件。请将整个 `MET/` 目录加入杀毒软件白名单后**重新完整解压**压缩包。
- **Q：Win32 端扫不到窗口，或连接后能截到图但点不动？**
  - A：绝大多数情况是**权限不足**。请右键 `MET.exe` → 属性 → 兼容性 → 勾选 **「以管理员身份运行此程序」**，并确保游戏未最小化、截图/输入方式为 `FramePool` + `Seize`。
- **Q：ADB 模拟器扫描不到设备？**
  - A：请确认模拟器已完全启动并开启 ADB 调试（MuMu 12 默认端口 `16384`，雷电默认 `5555`）；必要时在连接设置中手动填写模拟器自带的 `adb.exe` 路径与连接地址。
- **Q：识别不到按钮或点击位置偏移？**
  - A：请确认游戏窗口或模拟器为标准 **16:9（推荐 `1280×720` 或 `1920×1080`）**，且未开启异形刘海屏或非标准拉伸。

## 3. 如何反馈 Bug

请前往 [GitHub Issues](https://github.com/Shaw-W/MET/issues) 提交反馈，并尽量附上：
1. 使用的控制器类型（Win32 / ADB）、服区（官服 / B服）、任务名称与选项；
2. `debug/maafw.log`、`debug/met_coop_watchdog.log` 以及当日日志文件；
3. `debug/on_error/` 或 `debug/coop_freeze/` 中对应的现场截图。
