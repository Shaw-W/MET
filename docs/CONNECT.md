# 连接配置教程（PC Win32 / ADB 模拟器）

MET 统一以 **横屏 16:9、短边 720（1280×720）** 作为识别基准。你可以按自己的游玩习惯选择 **PC 桌面端** 或 **安卓模拟器**。

---

## 一、Win32 PC 桌面端（推荐）

### 1. 以管理员身份运行 MET（关键）
《悠久之树》PC 客户端通常以管理员权限运行；若 MET 权限低于游戏，Windows 会拦截鼠标点击与截图。
- **推荐设置**：右键 `MET.exe` → **属性** → **兼容性** → 勾选 **「以管理员身份运行此程序」** → 确定，以后直接双击即可。

### 2. 检查游戏窗口设置
1. 启动《悠久之树》PC 客户端（窗口类名 `UnityWndClass`，标题 `eternaltree` / `悠久之树`）。
2. 在游戏内设置为 **标准 16:9 窗口模式**（支持 `1280×720`、`1920×1080`、`2560×1440` 等，引擎会自动按短边 720 等比缩放）。
3. 挂机期间请**不要最小化游戏窗口**（最小化后 Windows 会暂停渲染画面；若已最小化，开启前置启动会自动还原）。

### 3. 在 MET 中连接 PC 窗口
1. 打开 `MET.exe`，在设备连接栏将控制器类型切换为 **`Win32 桌面端`**。
2. 点击 **刷新 / 扫描窗口**，列表会自动匹配到 `eternaltree`（或 `悠久之树`）。
3. 选中该窗口并点击 **连接**（默认已配置最优组合：`FramePool` 截图 + `Seize` 键鼠，通常无需手动修改）。
4. 连接成功后预览区正常显示游戏画面，即表示连接完成。

### 4. 配置自动启动游戏（可选，推荐）
1. 在前置任务中开启 **`启动 eternaltree.exe`**。
2. **游戏路径**默认 **「自动判断」**：自动读取上次连接记录与常见 TapTap 安装目录（`C/D/E/F:\TapTap\PC Games\176733\*\eternaltree.exe`）。
3. 若安装在自定义路径，切换为 **「手动填写」** 并选择 `eternaltree.exe` 即可。
4. 若游戏已在运行，前置任务会**秒级检测跳过**，不会重复多开。

> [!TIP]
> **联机卡死自动重启续刷前提**：请保持 MET 设置中的 **本地 Web 服务** 为开启状态（默认开启，端口 `12701`）。发生断网黑屏或软卡死时，`agent/met-service.exe` 会自动强杀并重启游戏、重连控制器并恢复联机。

## 二、ADB 安卓模拟器

### 1. 配置模拟器分辨率与 ADB 调试
1. 推荐使用 **MuMu 模拟器 12**（或其他支持标准 ADB 的安卓模拟器）。
2. **显示设置**：分辨率设为 **`1280×720`（平板/横屏模式）**，DPI 建议 `240`，关闭异形屏/刘海屏。
3. **开启 ADB 调试**：
   - **MuMu 模拟器 12**：右上角菜单 → 设置中心 → 其他 → 开启 **ADB 调试**（默认端口通常为 `16384`，多开顺延 `16416` 等）。
   - **雷电模拟器**：设置 → 其他设置 → 开启 **ADB 调试**（默认端口通常为 `5555`）。

### 2. 在 MET 中连接模拟器
1. 启动模拟器并打开 `MET.exe`。
2. 在连接设置中选择控制器 **`ADB 模拟器`**。
3. 选择对应服区资源：
   - **官服**：默认 `resource/base`
   - **B服**：自动叠加 `resource/bilibili`（独立包名 `com.bilibili.yjzs.bili`）
4. 点击 **扫描设备**，选中扫描到的模拟器实例并点击 **连接**。
5. **若扫描不到设备**：
   - 确认模拟器已完全启动并开启 ADB 调试；
   - 可在连接设置中手动指定模拟器自带的 `adb.exe` 路径（如 `MuMuPlayer-12.0\shell\adb.exe`）与连接地址（如 `127.0.0.1:16384`）。
