# MET (Maa Eternal Tree)

基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 与 [MXU](https://github.com/MaaXYZ/MXU) 全新架构开发的《悠久之树》自动化助手。

功能设计参考 [MAATree](https://github.com/caicai00001/MAATree)，底层全面升级至 **MaaFramework PI V2 协议** + **MXU 前端**，并提供纯 GitHub Actions 自动化打包流水线。

## 计划支持的功能

- **平台与环境**：Windows (`x86_64`)，支持官服 + B服，支持 ADB（模拟器）与 Win32（桌面端）
- **日常自动化**：启动游戏、每日物资、行会签到与捐赠、素材关卡扫荡、困难与极难主线扫荡、每日任务领奖
- **战斗与活动周回**：多人战斗、神眠之地、紧那罗击退战、神狱桃园乡领奖、探索活动领奖
- **稳定性保障**：自动补体、自动建房、卡死重启、掉线重连、自动跨夜
